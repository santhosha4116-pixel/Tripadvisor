# Travel Guide Website 🌍✈️

A modern and responsive **Travel Guide Website** built from scratch using **HTML5 and CSS3**. The project provides a clean travel experience with featured destinations, hotels, restaurants, search functionality, and responsive listing cards.

### 🛠️ Technologies & Tools

* **HTML5** — Semantic website structure
* **CSS3** — Styling, layouts, animations, and responsive design
* **CSS Flexbox & Grid** — Responsive page layouts
* **CSS Media Queries** — Mobile, tablet, and desktop responsiveness
* **Visual Studio Code** — Development
* **Git & GitHub** — Version control and project management

### 💻 Languages

* HTML
* CSS

### ✨ Key Features

* Custom travel brand and modern UI design
* Responsive header with logo, search bar, and navigation
* Navigation links for Hotels, Flights, and Restaurants
* Destination search section with filters
* Featured destination cards
* Hotel and restaurant listing cards
* Ratings and short descriptions
* Hover effects and interactive UI elements
* Fully responsive design for mobile, tablet, and desktop
* Original design created without cloning existing travel websites

### 🎯 Project Objective

This project was created to practice **HTML structure, CSS styling, Flexbox, CSS Grid, responsive design, and modern UI development** while building an original travel website from scratch.
